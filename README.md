# 家储日记

家庭库存管理应用（单文件网页版），打包为 Android APK 使用，全程AI完成。

## 功能
- 商品管理：名称、分类、数量、单价、购买渠道、单位、存放位置、建档时间
- 入库 / 出库 / 撤销出库 / 修改资料
- 库存归零自动归档，只增不删（写入式台账）
- 多库存支持：新建库存、删除库存（商品自动转移到第一个库存）、录入可选所属库存
- 操作流水与系统操作全程记录
- 按建档时间 / 操作时间查找
- 导入 / 导出 Excel（对齐源表格式）
- 桌面小部件：显示全部在库商品（白底、可滑动、不含零库存商品）
- 新建 / 删除库存需管理密码

## 文件
- `家庭库存管理系统.html` — 单文件网页源码
- `家储日记.apk` — 安卓安装包（见 Release）

数据保存在本机浏览器/应用内，不上传服务器。
